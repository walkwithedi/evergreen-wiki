# 知识库客户端：浏览器里的安装程序

由本机提供、在浏览器中打开的页面，适合不用终端的人：安装技能、建库并告诉助手，以后还可以备份、回滚、移动知识库、卸载。页面上列出已登记的知识库、哪些助手装了技能，以及 OpenCode 是否就绪。问题、预览和各项安全检查都来自 `install.py` 及其 `backup`、`rollback`、`move`、`uninstall` 子命令，本工具只是把它们显示在页面上，两者行为一致。

本版只包含安装与知识库管理。在页面中直接和助手对话将在后续版本提供；在此之前请照常打开助手。

[English](README.md)

## 文件

| 文件 | 说明 |
| --- | --- |
| `kb_client.py` | 本地服务：运行安装程序的各个步骤，把其中的问题转给页面 |
| `web/` | 页面（`index.html`、`app.js`、`style.css`）；纯 HTML、JavaScript 和 CSS，不从网络加载任何内容 |
| `kb-client.desktop` | 双击入口，打开一个终端窗口运行 `kb_client.py`，并用默认浏览器打开页面 |

## 运行要求

- Linux 桌面，Python 3.8 及以上（只用标准库），以及完整的 evergreen-wiki 文件夹：本工具调用上两级目录里的 `install.py` 和技能。
- 支持现代 JavaScript（`fetch`、`EventSource`）的浏览器，如较新的 Firefox 或 Chromium。

不需要联网。电脑不能联网时，从 [Releases](https://github.com/walkwithedi/evergreen-wiki/releases) 下载 evergreen-wiki-v<版本>.zip 拷过去解压，从 `tools/kb-client/` 启动。

## 使用

1. 双击 `kb-client.desktop`（知识库）。第一次双击时桌面可能询问是否信任或运行，选信任并启动。双击后只打开了文本时，在本文件夹打开终端，运行 `python3 kb_client.py`。页面会在默认浏览器中打开，终端窗口里显示页面地址。
2. 在左侧选择要做的事：
   - 安装与建库：选择助手，安装三个技能，建一个知识库（类型、文件夹、范围；写入前先给预览），并把知识库说明行写进助手的指令文件。选到已有知识库的文件夹时按原样登记。要再加一个库时再选一次。
   - 备份、回滚、卸载：同 `install.py backup`、`rollback`、`uninstall`（见 docs/manual-setup.zh-CN.md 第 6 节）。
   - 移动知识库，或点某个库下面的「移动」：选要移到哪个文件夹里，然后是 `install.py move` 的预览与确认。
3. 每一步输出的文字显示在它的问题上方。问文件夹时有「浏览…」按钮，打开文件夹浏览器：从家目录或已挂载的移动磁盘开始，逐级打开，选定一个文件夹。推荐的文件夹还不存在时，浏览器从离它最近的已有上级文件夹打开，并把其余部分填为新建的文件夹名，直接选定即回答推荐的文件夹；清空该名称则回答所选文件夹本身。
4. 「取消这一步」在当前问题处停止这一步，已完成的部分保留。「退出」停止客户端。关闭页面后，客户端也会在一段时间后自动停止（`--idle`）。

输入的不是绝对路径时，按家目录下的相对路径处理。

选项：`--lang en|zh` 指定语言（默认按系统语言），`--port N` 指定端口（默认自动选空闲端口），`--no-browser` 不打开浏览器、只显示地址，`--idle 秒数`（没有页面打开且没有步骤在运行达到这么久后停止；0 表示不自动停止；默认 120），`--log-level`。「安装与建库」还可用 `--agent <目标>` 和 `--preset life|work` 预先回答这两题，用 `--descriptions <文件>` 替换技能描述，与 `install.py` 相同；可以写一个包装脚本或复制一份 .desktop 入口，为一组使用者固定这些选项。

## 安全

- 服务只监听 127.0.0.1。打开的地址带一个随机令牌；不带令牌或主机名不对的请求一律拒绝，浏览器里的其他网页无法调用本服务。
- 同一时间只运行一个步骤。文件夹浏览器只列出文件夹和文件名；客户端本身不写任何东西，写入的只有安装程序各步骤在确认后写的内容。

## 在桌面上检查

单元测试按页面的方式通过 HTTP 回答问题。改动后请在真实桌面上检查：

1. 双击入口能打开终端窗口，并在默认浏览器中打开页面。
2. 安装与建库：文件夹浏览器从推荐位置打开（或从最近的已有上级打开并填好新文件夹名），能看到已挂载的移动磁盘，选定后的路径出现在问题里；确认前能看清预览。
3. 移动：移动后页面上该库显示新位置，重启助手后能在新位置查到库里的内容。
4. 卸载：知识库文件夹默认保留，逐个选定并输入确认词后才删除。
5. 「取消这一步」停止当前步骤且不再改动任何东西；「退出」停止客户端，终端窗口随之关闭。
