# 桌面安装：弹窗版安装程序

在 Linux 桌面上用菜单和弹窗运行 evergreen-wiki 安装程序，适合不用终端的人：安装技能、建库并告诉助手，以后还可以备份、回滚、移动知识库、卸载。问题、预览和各项安全检查都来自 `install.py` 及其 `backup`、`rollback`、`move`、`uninstall` 子命令，本工具只是把它们显示成弹窗，两者行为一致。

[English](README.md)

## 文件

| 文件 | 说明 |
| --- | --- |
| `desktop_setup.py` | 菜单与弹窗（zenity）；没有 zenity 或不在图形桌面时改为在终端问答 |
| `evergreen-wiki-setup.desktop` | 双击入口，在终端窗口中运行 `desktop_setup.py` |

## 运行要求

- Linux 桌面，Python 3.8 及以上（只用标准库），以及完整的 evergreen-wiki 文件夹：本工具调用上两级目录里的 `install.py` 和技能。
- 弹窗需要 `zenity`。没有时，或不在图形桌面中时，同样的问题在终端里问。

不需要联网。电脑不能联网时，从 [Releases](https://github.com/walkwithedi/evergreen-wiki/releases) 下载 evergreen-wiki-v<版本>.zip 拷过去解压，从 `tools/desktop-setup/` 启动。

## 使用

1. 双击 `evergreen-wiki-setup.desktop`（知识库设置）。第一次双击时桌面可能询问是否信任或运行，选信任并启动。双击后只打开了文本时，在本文件夹打开终端，运行 `python3 desktop_setup.py`。
2. 在菜单里选择：
   - 安装与建库：选择助手，安装三个技能，建一个知识库（类型、文件夹、范围；写入前先给预览），并把知识库说明行写进助手的指令文件。选到已有知识库的文件夹时按原样登记。要再加一个库时再选一次。
   - 备份、回滚、卸载：同 `install.py backup`、`rollback`、`uninstall`（见 docs/manual-setup.zh-CN.md 第 6 节）。
   - 移动知识库：选一个已登记的库，在文件夹选择器里选要移到哪个文件夹，然后是 `install.py move` 的预览与确认。
3. 每项做完回到菜单；选「退出」或关闭菜单即结束。

问文件夹时不给推荐位置：先显示问题，再从家目录打开文件夹选择器。在选择器里取消即取消这一项；在预览里修改已选的文件夹时，选择器从该文件夹打开，取消则保留原来的选择。每一步输出的文字显示在下一个弹窗里，较长的预览先在可滚动的窗口中显示。关闭列表、输入框或文件夹弹窗即取消当前这一项，关闭是否题等于回答「否」；已完成的步骤保留。

选项：`--ui zenity|tty`（或环境变量 `EVERGREEN_SETUP_UI`）强制用弹窗或终端，`--lang en|zh` 指定语言（默认按系统语言），`--log-level`。「安装与建库」还可用 `--agent <目标>` 和 `--preset life|work` 预先回答这两题，用 `--descriptions <文件>` 替换技能描述，与 `install.py` 相同；可以写一个包装脚本或复制一份 .desktop 入口，为一组使用者固定这些选项。

## 在桌面上检查

单元测试用一个假的 zenity 应答弹窗。改动后请在真实桌面上检查：

1. 双击入口能打开终端窗口和菜单弹窗；没有 zenity 时菜单在终端里问。
2. 安装与建库：问知识库文件夹时从家目录打开选择器，不预选任何文件夹，取消则什么都不写；确认前能看清预览，最后的弹窗列出可以试的说法。
3. 移动：文件夹选择器能打开，预览显示原位置和新位置，重启助手后能在新位置查到库里的内容。
4. 卸载：除非勾选并输入确认词，否则不删除任何知识库文件夹。
5. 关闭列表或输入框弹窗时停止当前这一项，不再做其他改动。
