# workbench：OpenCode 工作台向导

[English](README.md)

开箱即用的离线工作台：把 [opencode-setup](../opencode-setup/README.zh-CN.md)（填个人 AK、关闭 opencode 启动时的联网下载、首次启动自检）和[知识库客户端](../kb-client/README.zh-CN.md)合在一起，双击后在浏览器里按三步走完，进入以对话为主的 OpenCode 工作台：在选定的工作文件夹里和助手对话、改文件，可以切换模型、接着以前的会话聊、查看每次改动的差异；知识库功能收在页面里，要用时再展开。

## 目录内容

| 文件 | 说明 |
| --- | --- |
| `启动OpenCode工作台.desktop` | 双击入口：打开一个终端窗口运行 `wk_web.py`，并在默认浏览器中打开向导页面。工作台发行包最上层另有同样的一份；入口可以发到桌面，见「使用方法」。 |
| `wk_web.py` | 本地服务：第 1、2 步复用 `../opencode-setup/ca_web.py`，以子进程运行 `codeagent-setup.sh` 的 `check`、`setup` 子命令；第 3 步启动 `../kb-client/kb_client.py`，取得它的页面地址交给向导页面跳转。只用 Python 3 标准库。 |
| `web/` | 向导页面（`index.html`、`app.js`、`style.css`），纯本地 HTML、JavaScript 和 CSS，不从网络加载任何内容。 |

## 运行环境要求

- 与 opencode-setup 相同：麒麟，bash 4.4 及以上，python3（系统自带即可，Python 3.8 及以上），Node 主版本 22 及以上，已安装 opencode，本机已有 OpenCode 配置（接口地址、模型和 AK 字段）。
- 支持 `fetch` 与 `EventSource` 的浏览器（较新的 Firefox 或 Chromium）。
- 可选：`pdftotext`（poppler-utils）。没有时助手会整份读取 PDF，速度更慢。
- 不需要联网，不需要安装第三方包。

## 发行包

在 Releases 里下载 `workbench-bundle-<版本>.zip`，拷到工作站上解压。解压后的文件夹最上层是启动入口和 `evergreen-wiki/` 文件夹（与同版本的 `evergreen-wiki-<版本>.zip` 内容相同）：

```
启动OpenCode工作台.desktop   启动入口（双击它）
evergreen-wiki/              知识库技能、tools/workbench、tools/opencode-setup、tools/kb-client 等
```

`evergreen-wiki/` 里的目录结构不能拆开。从仓库直接运行时，双击 `tools/workbench/` 里的入口即可。opencode-setup 或仓库不在默认位置时，可以用 `python3 wk_web.py --codeagent <目录> --wiki <仓库目录>` 指定。

## 使用方法

1. 双击解压后最上层的 `启动OpenCode工作台.desktop`（`evergreen-wiki/tools/workbench/` 里的那份也一样）。第一次双击时，桌面可能询问是否信任或运行，选择信任并启动。如果只打开了文本，就在 `tools/workbench` 文件夹里打开终端，运行 `python3 wk_web.py`。
   - 发到桌面：可以右键入口「发送到桌面快捷方式」，或把它复制、链接到桌面。入口依次在自己所在的文件夹、旁边的 `evergreen-wiki/tools/workbench/` 和向导记下的位置里找向导：桌面上是链接时直接找到；是副本时，用向导每次启动时记下的位置（`~/.config/work-kb/location`），所以先在解压的文件夹里双击启动过一次即可。都找不到时，终端窗口里会提示先在解压的文件夹里双击一次。解压的文件夹挪了位置后，在新位置双击一次，桌面上的入口就跟着更新。
2. 在页面上按顺序完成三步。前一步没完成时，后一步的按钮点不了：
   1. 环境检查：查看 Node 版本、opencode 和本机的 OpenCode 配置。Node 版本不够时，按提示切换版本，然后关闭终端、重新双击启动。
   2. 填写个人 AK 并自检：粘贴 AK 后点「配置并自检」，做法同 opencode-setup 的一键配置：先测试，通过后才写入；写入前会备份，然后关闭联网下载，再做首次启动自检。`~/.bashrc` 里出现 codeagent-setup 标记段后，这一步就算完成。已经用别的办法配好 OpenCode 的，点「已配置，跳过」（第 1 步完成、本机有 OpenCode 配置时可用）：向导记住这个选择，此后只要本机还有 OpenCode 配置就算完成，不再检查 AK；AK 失效时要到对话里才会发现，那时回到这一步重新配置。AK 申请位置与 Node 切换方法的提示可以按本机改写，见 opencode-setup 的「本机提示」。
   3. 打开工作台：先选版本，再点「打开工作台」，本页会跳到知识库客户端。它以 `--chat-first` 启动，打开时以对话为主：
      - 版本：简易版（默认，客户端加 `--simple`）只有安装与建库、备份，技能只能查看；全版另有回滚、移动、卸载，以及技能的新建、导入、修改和回滚。向导记住所选版本。工作台已经在运行而换了版本时，向导先让它退出，再按新版本启动，正在进行的对话会中断，可以从「历史会话」接着聊。工作台有知识库管理步骤（如安装与建库、备份）在运行，或有对话还在处理、等你回答时（入库也在对话里进行），不换版本：先等它完成，或在工作台里点「停止」。
      - 工作文件夹：在对话上方点「更换…」选一个文件夹（最近 5 个可以直接再选；不能是家目录本身或系统文件夹）。OpenCode 就在这个文件夹里启动，每个文件夹记住各自的一组对话窗口；换文件夹时所有窗口都要空闲。助手在这个文件夹里读、改文件不再询问；运行命令（只读命令除外）和文件夹以外的操作仍会弹出授权卡片。客户端不备份被改动的文件，工作文件夹请选用有版本管理（git）或有备份的文件夹。
      - 模型：配置里有多个模型时，可以为当前对话换一个；开新对话后恢复默认。
      - 对话窗口：对话区上方一排标签，每个标签是一个独立的对话，点「＋」新开（最多 8 个），点「×」关闭（对话仍保存，可从「历史会话」再打开）。后台窗口在处理、有卡片等你或有新回复时，标签上会标出。安装与建库、备份等管理步骤运行期间，对话里的助手要改知识库时一律先弹卡片询问。「全部允许」按窗口各自开关。
      - 历史会话：列出这个文件夹里以前的对话，点一个在新窗口里接着聊（已经开着的就切过去）。
      - 查看改动：助手改了文件后，步骤下面可以展开查看这次改动的差异。
      - 技能：对话左边列出助手会用的技能，每个一行，点开看说明和触发口令；技能多时可以筛选。点左栏右上角的「«」可以把左栏收拢成一条窄栏，对话区随之变宽，点窄栏展开；浏览器会记住是否收拢。
      - 知识库：点左上角标题旁的「知识库」展开，知识库列表、管理按钮和首次使用清单的知识库各项都在里面，浏览器会记住是否展开。界面为中文，技能只装到 OpenCode，建的是工作库，主题页由脚本生成。入库在对话里提出，写明文件或文件夹路径。入库时需要你决定的事项（新主题、新实体、可能的新版本、冲突）显示在对话区上方的「等待确认」里，可以在表单里选，也可以直接在对话里回答；对话区上方的「随手记」把一句话立即记进知识库。1.x 建的知识库不读，要在空文件夹里新建知识库，把材料重新入库。选简易版时没有回滚、移动、卸载和技能管理，要用这几项时改选全版，或在终端里用仓库根目录的 `install.py` 做。第一次用知识库时，展开后按清单点「安装与建库」。
3. 以后再双击时，如果前两步已经完成，页面倒数 3 秒后会直接打开工作台。点「留在本页」可以停下来，比如要更换 AK。
4. 工作台（知识库客户端）是单独运行的。向导停止后，工作台页面照常可用；关掉工作台页面一段时间后，客户端会自己停止。

向导的两项选择记在 `~/.config/work-kb/state.json`，日志写到 `~/.config/work-kb/logs/wk-web-日期.log`（只有本人可读，保留 7 天）。

## 版本说明

随 evergreen-wiki 发版，版本号与仓库一致，变更记在仓库的 CHANGELOG.md。

- 4.0.0：客户端自己入库（入库、空闲时补抽卡片、投放文件夹自动入库）；客户端正在入库、有对话在处理或等你回答、有管理步骤在运行时，不切换简易版和全版。
- 3.0.0：并入 evergreen-wiki 的 `tools/workbench/`，直接使用本仓库的 `tools/kb-client` 和 `tools/opencode-setup`，不再另行下载知识库发行包；发版时附工作台发行包 `workbench-bundle-<版本>.zip`。`~/.config/work-kb/` 下的选择、位置与日志沿用原路径。
