## Which file to download / 下载哪个文件

| File | Use it for |
| --- | --- |
| `workbench-bundle-v<version>.zip` | the offline workbench for a Kylin workstation with OpenCode: unpack it and double-click the entry at the top, which sets OpenCode up with a personal key and opens the knowledge base client. 离线工作台：麒麟工作站上解压后双击最上层的入口，配置 OpenCode 的个人 AK 并打开知识库客户端。 |
| `evergreen-wiki-v<version>.zip` | the whole repository: skills, `install.py` (setup, backup, rollback, move, uninstall), tools/workbench, tools/opencode-setup, tools/kb-client, tools/doc2kb, the sample library and the docs. 完整仓库：在终端里用 `python3 install.py` 安装时用这个。 |
| `doc2kb-v<version>.zip` | the document converter alone. 只要文档转换器时用。 |

Libraries made by 2.0 or 3.0 (all sources in one folder) stay with v3.0.0; libraries in Google Drive and the ChatGPT versions of the skills stay with v2.0.0. 2.0、3.0 建的知识库（来源都在一个文件夹里）请用 v3.0.0；Google Drive 上的知识库和 ChatGPT 版 skill 请用 v2.0.0。

How the pieces fit: [README](https://github.com/walkwithedi/evergreen-wiki#how-it-fits-together) / [中文说明](https://github.com/walkwithedi/evergreen-wiki/blob/main/README.zh-CN.md#整体结构与下载).
